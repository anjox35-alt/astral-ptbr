# Como contribuir

Astral é uma demonstração independente em PT-BR. O escopo atual é o mapa básico calculado no navegador.

Antes de propor uma mudança, execute `npm ci`, `npm run typecheck`, `npm test` e `npm run build`. Descreva o problema e a validação realizada. Mudanças no cálculo precisam de evidência de referência e regressão relevante. Use dados sintéticos nos exemplos e preserve os avisos MIT.

Não publique dados pessoais de nascimento, chaves, tokens ou arquivos `.env.local`. Os datasets de interpretação e o corpus Tian Ji não integram esta adaptação.
